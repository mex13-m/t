# محمّل الفيديو

موقع لتحميل فيديوهات TikTok و YouTube و Facebook بأعلى جودة، مبني على Node.js + yt-dlp.

## المتطلبات
- Node.js 18+
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) و [ffmpeg](https://ffmpeg.org) مثبتان على الجهاز/السيرفر

## التشغيل محلياً
```bash
npm install
npm start
# افتح http://localhost:3000
```

## النشر
GitHub Pages لا يشغّل Node.js. انشر المشروع على Render أو Railway أو VPS باستخدام `Dockerfile` المرفق (يثبّت yt-dlp و ffmpeg تلقائياً).

## تنبيه
حمّل فقط المحتوى الذي تملكه أو لديك إذن بتحميله، والتزم بشروط استخدام كل منصة.
